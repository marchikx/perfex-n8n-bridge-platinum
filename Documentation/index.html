Installation

Installing N8N Bridge is quick and straightforward. Follow these steps to get started:

Requirements

  • Perfex CRM 2.3.0 or higher
  • PHP 7.4 or higher (PHP 8.x recommended)
  • cURL extension enabled
  • MySQL 5.7+ or MariaDB 10.2+

Step 1: Upload Module

Upload the n8n_bridge folder to the modules/ directory in your Perfex CRM installation.

Directory Structure 
perfex_crm/
├── modules/
│   └── n8n_bridge/
│       ├── controllers/
│       ├── models/
│       ├── views/
│       ├── libraries/
│       ├── language/
│       ├── install.php
│       └── n8n_bridge.php

Step 2: Activate Module

  1. Log in to Perfex CRM admin panel
  2. Navigate to Setup → Modules
  3. Find "N8N Bridge" in the module list
  4. Click Activate

Step 3: Configure

After activation, navigate to Setup → N8N Bridge to configure your webhook settings.

Installation Complete!
The module will automatically create the necessary database tables and initialize default settings.

Event-Based Routing

Send different events to different N8N workflows by configuring override URLs per event type.

How It Works

  1. Go to Triggers & Routing tab
  2. Enable the events you want to trigger
  3. Click Override URL to expand routing options
  4. Enter a custom webhook URL for that specific event
  5. Leave empty to use the global webhook URL
Use Case Example:
Send invoice events to a billing workflow and lead events to a sales automation workflow.

Security

HMAC-SHA256 Signature Verification

Every outbound webhook includes an HMAC-SHA256 signature in the X-Perfex-Signature header. Use this to verify the request authenticity in N8N.

Verifying Signatures in N8N

N8N Function Node - JavaScript 
const crypto = require('crypto');
const secret = 'YOUR_HMAC_SECRET';
const payload = JSON.stringify($input.all()[0].json);
const signature = crypto
  .createHmac('sha256', secret)
  .update(payload)
  .digest('hex');

// Compare signatures
if (signature === $input.all()[0].headers['x-perfex-signature']) {
  return [{ json: { verified: true, data: $input.all()[0].json } }];
}
return [{ json: { verified: false } }];
Security Best Practices:
• Always verify HMAC signatures in production
• Use HTTPS for all webhook URLs
• Regenerate tokens periodically
• Never expose tokens in client-side code

Queue System

The resilient queue system ensures webhook delivery even when N8N is temporarily unavailable.

Exponential Backoff Schedule

Attempt Retry After Description
1 5 minutes Quick retry for transient failures
2 15 minutes Allow time for recovery
3 1 hour Longer wait period
4 4 hours Extended recovery time
5 12 hours Final attempt before marking as dead

Queue Statuses

  • Pending - Waiting for next retry attempt
  • Processing - Currently being processed
  • Completed - Successfully delivered
  • Dead - All retry attempts exhausted

Troubleshooting

Webhooks Not Sending

  1. Verify the module is enabled in settings
  2. Check that the webhook URL is correctly configured
  3. Ensure the specific event trigger is enabled
  4. Test the connection using the "Test Connection" button
  5. Check the Health tab for system issues

Queue Items Stuck

  1. Go to Health & Support tab
  2. Click Reset Stuck Queue Items
  3. Verify Perfex CRM cron job is running properly
  4. Check if N8N webhook URL is accessible

Signature Verification Failing

  1. Ensure you're using the correct HMAC secret from settings
  2. The signature is calculated on the raw JSON body
  3. Check for any middleware modifying the request body
  4. Verify JSON encoding matches (no extra whitespace)

Inbound Webhook Not Working

  1. Verify the inbound token in the URL is correct
  2. Ensure you're sending a POST request
  3. Check the Content-Type header is application/json
  4. Validate your JSON payload structure
  5. Check Perfex CRM logs for error messages
Need More Help?
Check the system logs at application/logs/ for detailed error messages. The module logs all errors with the prefix "N8N Bridge:".
